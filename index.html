如何自由選擇「儲存資料夾」路徑？

為了防範病毒惡意修改電腦，瀏覽器在安全限制下，禁止網頁在不詢問的情況下直接指定硬碟絕對路徑。本系統已為您做出最佳優化：

方法一：使用本機另存對話框（系統已內建）

我們已內置 File System Access 技術。當您使用 Chrome / Edge 瀏覽器點擊下載時，系統會直接彈出「另存新檔」視窗，您可以自由選擇任何硬碟位置 (例如：桌面、D槽、隨身碟)，並能在儲存前即時修改名稱。

方法二：啟用瀏覽器「下載前詢問」設定

若您使用的是 Safari 或 Firefox，強烈建議您花費 10 秒鐘開啟瀏覽器的安全詢問：

  • Chrome / Edge：設定 ➔ 下載 ➔ 啟用「下載每個檔案前先詢問儲存位置」
  • Safari：偏好設定 ➔ 一般 ➔ 下載項目儲存位置 ➔ 設為「每次下載時詢問」
  • Firefox：設定 ➔ 一般 ➔ 下載 ➔ 勾選「每次都問您要將檔案儲存至何處」
